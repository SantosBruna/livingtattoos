# Projeto: Criação de uma rede social para tatuados

## 📊 Sobre o Projeto
TCC da graduação em Tecnologia em Sistemas de Informação na CEDERJ cujo o certificado sai pela UFF. O objeto é o desenvolvimento de uma rede social para tatuados onde o usuário realiza o escaneamento da sua tatuagem no aplicativo e esta tatuagem ganha vida e passa a se comportada com algumas características pré estabelecidas. As conversas serão feitas por cada tatuagem, que será a representação da pessoa no app.
